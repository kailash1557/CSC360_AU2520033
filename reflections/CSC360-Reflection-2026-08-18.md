# CSC360 Reflection — 18/08/2026

After drawing our first square with AI assistance in the last session, this class focused on actually understanding the logic behind it. To draw a square we need two basic pieces of information: a center position and a side length. From the center point, each corner can be calculated by adding or subtracting half the side length along the x and y axes, giving us the top left, top right, bottom left, and bottom right coordinates. Once those four corners are known, the square is just a matter of calling drawLine between the correct pairs of corners. We also touched on how side length is measured in pixels, and how the physical size of a shape on screen depends on the display resolution and size, with larger displays showing more physical length but at the cost of some crispness.

We also went deeper into setting up the development environment properly. This included verifying the JDK installation using java -version and javac -version, installing a JDK 21 LTS build, and configuring the JAVA_HOME environment variable so Java tools are accessible system wide. We then installed Apache Maven, set up the MAVEN_HOME variable, added it to the system PATH, and verified everything worked with mvn -version.

Finally we discussed how a proper Java project should be structured, with separate src/main/java and src/test/java directories, along with a README and gitignore at the root. This connected back to the square drawing exercise, since we started applying object oriented principles to represent a shape like a rectangle as its own class rather than just loose drawing calls. Overall the session moved us from writing quick standalone code to thinking about proper project setup and structure.
